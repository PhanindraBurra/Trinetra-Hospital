INSTRUCTIONS FOR DOCTOR PHOTOS:

Place actual doctor JPG or PNG photos into this directory with the following filenames:

1. dr_critical_care.jpg (or .png / .svg) -> Critical Care & Emergency Medicine Specialist
2. dr_general_medicine.jpg (or .png / .svg) -> General Medicine & Diabetology Physician
3. dr_pediatrics.jpg (or .png / .svg) -> Pediatrician & Child Health Specialist
4. dr_gynecology.jpg (or .png / .svg) -> Obstetrics & Gynecology Specialist
5. dr_ortho.jpg (or .png / .svg) -> Orthopedics & Trauma Specialist
6. dr_ent.jpg (or .png / .svg) -> ENT (Ear, Nose & Throat) Specialist

Note: High-resolution professional portrait photos (approx 400x500 pixels, vertical orientation) look best.
When you drop in new photos, you can update the filenames in `/data/doctors.json`.
