INSTRUCTIONS FOR HOSPITAL LOGO:
==================================
The site currently uses the vector SVG logo in `/public/assets/logo/logo.svg`.
If you have the official PNG or high-res graphic logo from Instagram / hospital board:

1. Drop your PNG image as:
   `/public/assets/logo/logo.png`
2. Update the `logo` path in `/data/hospital.json` to:
   "/assets/logo/logo.png"

The brand colors currently extracted and active across the design system:
- Primary: #0E7490 (Deep Ocean Teal)
- Secondary: #0284C7 (Medical Sky Blue)
- Accent: #0D9488 (Teal Vitality Green)
- Dark Text: #0F172A (Slate Navy 900)
- Light Tint: #F0F9FF & #F8FAFC
